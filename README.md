# LGTM Sticker

**English** | [日本語](README.ja.md)

A Chrome extension that fetches a random GIF from [LGTM Gifs](https://www.lgtmgifs.com/) and copies it to your clipboard as Markdown.
It's meant for pasting into pull request approval comments.

## Features

- Click the extension icon to copy a random LGTM GIF as `![name](URL)`
- Calls the API on every run, so you get a different GIF each time
- Preview the GIF in the popup, and click "Another GIF" to pick a new one
- Keyboard shortcut (`Alt+Shift+L`)
- If GitHub's "Finish your review" dialog is open in the current tab, the Markdown is also inserted into its comment box (clicking "Another GIF" replaces the previously inserted one)

## Installation

1. Build the TypeScript source: `npm install && npm run build` (outputs `dist/popup.js`)
2. Open `chrome://extensions` in Chrome
3. Turn on "Developer mode" in the top right
4. Click "Load unpacked" and select this folder (`lgtm-sticker`)

During development, `npm run watch` rebuilds on save. Reload the extension in `chrome://extensions` to pick up changes.

## Usage

1. Click the extension icon in the toolbar (or press `Alt+Shift+L`)
2. When it says "Copied ✓", paste it into a PR comment or anywhere else
3. If you don't like the GIF, click "Another GIF"

Example of the copied text:

```markdown
![Creed Ship It](https://media.giphy.com/media/xxxxxxxx/giphy.gif)
```

You can change the shortcut at `chrome://extensions/shortcuts`.

## How it works

The "Random Gif" button on lgtmgifs.com calls the API only once, when the page loads, and copies that result.
That's why you keep getting the same GIF until you reload the site.

This extension calls the following API directly every time it runs:

```
GET https://lgtm-api.vercel.app/api/gifs/random
```

Example response:

```json
{
  "id": "...",
  "name": "Creed Ship It",
  "slug": "creed-ship-it",
  "url": "https://media.giphy.com/.../giphy.gif",
  "smallUrl": "https://media.giphy.com/.../200w.webp",
  "mp4Url": "...",
  "width": 200,
  "height": 150,
  "tags": []
}
```

The API doesn't return CORS headers, so `manifest.json` grants access to `https://lgtm-api.vercel.app/*` through `host_permissions`.

## Permissions

| Permission | Purpose |
| --- | --- |
| `clipboardWrite` | Copy to the clipboard |
| `activeTab` / `scripting` | Insert the Markdown into GitHub's review comment box in the current tab |
| `host_permissions: https://lgtm-api.vercel.app/*` | Call the random GIF API |

## Notes

- `lgtm-api.vercel.app` is not an officially published API. It may stop working if the site changes.
- All GIFs are the property of their respective owners.
